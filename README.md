# Задача: Создание API для веб-платформы для знакомства и общения между пользователями с возможностью поиска потенциальных партнеров по различным критериям.

---
# Реализовано:

## Подключение к базе PostgresSQL, если она недоступна, то работа происходит в MySQL Lite. 

## 01 UserProfile (модель Пользователя системы), регистрация по email.
### В форме списка пользователей реализован поиск людей по:
### - Возраст
### - Имя
### - Город
### - Логин
### - Пол
### - Возраст расчитывается автоматически в зависимости от выбранного из списка года (минус 100 и минус 18 лет от текущего года, что бы не было пользователей ниже 18 лет и не вводился год больше текущего).


## 02 Gallery (модель, хранящая картинки), создаётся папка с ID пользователя и там хранятся все его фотографии.

## 03 GalleryRating (модель хранящая всю историю лайков и дизлайков пользователя).

## 04 Добавление в друзья.

## 05 Чат для общения.
